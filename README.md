# Zudio_Store_Analysis
Searched for the Zudio Dataset in Kaggle Webisite and Download.
Created a jupyter python file to Clean and Validate the data and find out some relationsips and charts.
Loaded the cleaned data into MySQL, Derived the Analytical relationship from the file.
After that Loaded the same file into Power BI and Created some DAX functions as per the Requirement and Created a Looking Good Dashboard.
